# 免費上線步驟（GitHub Pages，0 元）

**結論**：協會只要開兩個免費帳號（Google、GitHub），其餘的程式推送、網站開啟、與試算表連線都由 Claude 處理。網址會是 `https://帳號名稱.github.io`，例如 `https://keelung-ocean-sports.github.io`。

## 為什麼選 GitHub Pages

| 方案 | 費用 | 協會網站可否使用 | 試算表更新 | 結論 |
|---|---|---|---|---|
| **GitHub Pages** | 免費 | 可（只禁止網路商店、商業交易等用途） | 每 30 分鐘自動；可按鈕立即更新 | **採用** |
| Vercel 免費版 | 免費 | 規定僅限個人非商業使用 | 約 5 分鐘 | 不建議，有違約下架風險 |
| Vercel Pro | 每月約 20 美元 | 可 | 約 5 分鐘 | 有預算再考慮 |

GitHub Pages 的限制：網站大小上限 1 GB（目前約 8 MB），每月流量建議上限 100 GB，一般協會網站用不完。

## 協會要做的事（約 20 分鐘）

### 1. 準備協會專用 Google 帳號
建議另開一個協會 Gmail，GitHub 和試算表都用它，日後換承辦人時把密碼交接即可，不會綁在個人帳號上。

### 2. 註冊 GitHub 並建立網站儲存庫
1. 到 github.com/signup，用協會 Gmail 註冊。**帳號名稱就是網址**，建議 `keelung-ocean-sports`（被用走就換 `kosc-keelung` 等，英數字和 `-`）。
2. 登入後按右上角「＋」→「New repository」。
3. Repository name 填 **`帳號名稱.github.io`**（例：`keelung-ocean-sports.github.io`）。
4. 選 **Public**，下面的選項都不要勾，按「Create repository」。

### 3. 讓 Claude 可以推送程式
1. 用剛才的 GitHub 帳號登入狀態，開啟 Connect GitHub 連結（Claude 會在對話中提供），按授權。
2. 依畫面安裝 Claude GitHub App，選「Only select repositories」→ 勾選剛建立的儲存庫。
3. 回到對話告訴 Claude 帳號名稱。

### 4. 建立網站內容試算表
1. 把「網站公開內容管理表_範本.xlsx」上傳到協會 Google 雲端硬碟，開啟後「檔案 → 另存為 Google 試算表」。
2. 全選 → 格式 → 數字 → 純文字。
3. 共用 →「一般存取權」改成「知道連結的任何人」→ 角色「檢視者」。
   這份試算表**只放可公開的內容**，報名名冊、保險名冊、體適能紀錄不可放在同一個檔案。
4. 把試算表連結貼給 Claude。

## Claude 接著會做的事
1. 推送網站程式到儲存庫。
2. 開啟 GitHub Pages、設定試算表 ID。
3. 執行第一次發布，確認網站讀得到試算表、照片與數據正確，再把網址給協會。

若 Claude 的權限無法開啟 Pages 設定，會請協會在儲存庫「Settings → Pages → Source」選「GitHub Actions」，點一下即可。

## 上線後的日常
- 改試算表：約 30–60 分鐘自動更新。
- 要立刻更新：儲存庫 → Actions →「更新並發布網站」→ Run workflow。
- 想用自己的網域（例如 .org.tw）：需另外付費購買，買了之後可直接綁定，網站不用改。
