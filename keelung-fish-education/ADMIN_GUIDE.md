# 管理操作說明（不需要懂程式）

網站的文字、活動、魚種、教材與成果，全部在 **Google 試算表「食魚教育網站公開內容管理表」** 修改。改完後，網站約 30 分鐘內自動更新。

> ⚠️ 這份試算表會公開到網路上。**姓名、電話、Email、地址、身分證、保險、健康、障別、特殊需求、緊急聯絡人、兒童資料**一律不可以放進來。報名與保險資料請放在另外的私人表單。

## 共通規則
- 第一列（欄位名稱）和分頁名稱**不要改**。
- `published` 填 `TRUE` 才會出現在網站；填 `FALSE` 就是下架（不用刪掉）。
- `order` 是排序，數字小的在前面。
- 日期一律寫 `2027-03-15` 這種格式。
- 一格要放好幾個值時，用 `|` 隔開，例如 `market|harbor|table`。
- `slug` 是網址代稱，只能用小寫英文、數字和 `-`，例如 `2027-0315-family-day`，設定後不要再改。

## 如何新增活動
1. 打開 Google 試算表，切到 `activities` 分頁。
2. 在最下面新增一列。
3. 填 `date`（日期）、`year`（民國年度，例如 116）。
4. 填 `title`（活動名稱）、`type`（體驗活動／校園課程／共融活動／教師培力／其他）、`location`、`participants`（實際人數）。
5. 填 `summary`（一兩句簡介）和 `content`（內容，空一行就是新段落）。
6. `stops` 填當天走過的站：`market`（市場）、`harbor`（漁港）、`tide`（潮間帶）、`table`（餐桌）。
7. 放照片：到 `photos` 分頁新增照片列（見下方），再把主圖的 id 填到活動的 `coverImage`。
8. `published` 填 `TRUE`。
9. 等待網站更新（約 30 分鐘）。急的話：GitHub → Actions →「更新並發布網站」→ Run workflow。

## 如何新增照片
- 方法一（最簡單）：照片上傳到雲端硬碟並設為「知道連結的任何人可檢視」，在 `photos` 分頁新增一列，`src` 填照片的公開網址。
- 方法二：把照片交給維護人員放進網站（速度較快、畫質較好）。
- 每張照片都要填 `alt`：用一句話描述照片內容，給看不到照片的人使用。
- `activitySlug` 填照片屬於哪一場活動，那張照片就會出現在該活動的照片牆。

## 如何新增魚種
1. 切到 `species` 分頁，新增一列。
2. 填 `name`、`category`（魚類、頭足類、蝦蟹類、貝類、海藻／石花菜、水產加工品）。
3. 其他欄位有資料再填，空白的欄位網站不會顯示。
4. `fishingMethods` 填相關漁法的 slug（例如 `longline|single-hook`）。
5. `published` 填 `TRUE`。

## 如何新增漁法
在 `fishing_methods` 分頁新增一列，`targetSpecies` 填相關魚種的 slug。

## 如何新增故事
在 `stories` 分頁新增一列。`content` 用「## 小標」分段，建議依序寫：為什麼辦這場？今天在哪裡？參與者實際做什麼？看到了什麼？學到了什麼？如何從海洋連到餐桌？這場留下什麼？
**只寫真的發生的事**，不要寫沒有紀錄的對話或感想。

## 如何新增教材
在 `materials` 分頁新增一列，`category` 填「親子一起玩／老師帶著教／活動現場用」，`pdfUrl` 填 PDF 的公開連結。

## 如何新增年度成果
1. 在 `results` 分頁新增該年度每個指標（`year` 填 116 等）。
2. `value` 填實際成果、`target` 填核定目標，兩個不要混在一起。
3. 數字經結案確認後，`published` 才改成 `TRUE`。
4. 網站會自動出現 `/results/116/` 成果館。

## 改錯了怎麼辦
- 網站有內建備份資料，試算表讀不到時會自動改用，不會整個壞掉。
- 每次更新後，可以到 GitHub → Actions → 最新一次執行 → Summary，看「食魚教育網站內容檢核」有沒有標紅的錯誤。
